# random-pair
2種類のリストからそれぞれ１つをランダムに選択する

## 使い方
`index.html` をブラウザで開き、リスト1・リスト2を入力して「選ぶ」を押す（スペースキーでも可）。

- 区切りなしで入力すると1文字ずつに分割される（例: `ABCDEFG`, `CAGED`）
- カンマか空白で区切ると項目ごとに分割される（例: `R35, 35R, 5R3`）
- 選ぶ組数とつなぎ文字（既定は「の」）は変更可能。入力内容はブラウザに保存される

結果の例: `AのG` `CのD` / `CのR35` `Fの35R`

## 公開
