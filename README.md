# random-pair
2種類のリストからそれぞれ１つをランダムに選択する

## 使い方
`index.html` をブラウザで開き、リスト1・リスト2を入力して「選ぶ」を押す（スペースキーでも可）。

- カンマか空白で区切ると項目ごとに分割される（例: `A, B, C, D, E, F, G`, `C, A, G, E, D`, `R35, 35R, 5R3`）
- 区切りなしで入力すると1文字ずつに分割される（例: `CAGED`）
- 選ぶ組数（既定は1）とつなぎ文字（既定は ` - `）は変更可能。入力内容はブラウザに保存される

### URLクエリ
設定は常にURLのクエリに反映されるので、そのままブックマークすれば同じ設定で開ける。
クエリがあれば前回の保存内容より優先される。

| キー | 内容 | 例 |
| --- | --- | --- |
| `a` | リスト1 | `a=A,B,C,D,E,F,G` |
| `b` | リスト2 | `b=R35,35R,5R3` |
| `n` | 選ぶ組数 | `n=1` |
| `sep` | つなぎ文字 | `sep=+-+`（` - `）、`sep=の` |

例: `https://rfeather99.github.io/random-pair/?a=A,B,C,D,E,F,G&b=R35,35R,5R3`

結果の例: `A - G` / `C - R35`（つなぎ文字を「の」にすると `AのG`）
